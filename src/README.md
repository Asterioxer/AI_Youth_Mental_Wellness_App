# Serenique - AI-Powered Youth Mental Wellness Platform

![Serenique Logo](./public/favicon.svg)

## 🌟 About Serenique

Serenique is a cutting-edge, AI-powered mental wellness web application specifically designed for youth. The platform combines advanced artificial intelligence with intuitive user experience to provide personalized mental health support, real-time mood analysis, and comprehensive wellness resources.

### ✨ Key Features

- **🤖 AI-Powered Chatbot**: 24/7 emotional support with advanced psychological understanding
- **📝 Intelligent Journaling**: Real-time mood detection and sentiment analysis
- **📊 Comprehensive Mood Tracking**: Visual charts and pattern recognition
- **🧘 Wellness Resources**: Guided meditation, breathing exercises, and self-care tools
- **🔒 Privacy-First**: Offline AI processing with local data storage
- **🎨 Youth-Centric Design**: Modern, calming interface optimized for young users

## 🚀 Getting Started

### Prerequisites

- Node.js 18.0.0 or higher
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sohampauli/serenique.git
   cd serenique
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to see the application running.

### Building for Production

```bash
npm run build
npm run preview
```

## 🎨 Design System

Serenique uses a custom design system built with:
- **Tailwind CSS v4** for utility-first styling
- **Glass morphism** effects for modern aesthetics
- **Motion/React** for therapeutic animations
- **Custom "Mind Garden" logo** representing growth and mental wellness

## 🔧 Technology Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Custom CSS
- **Animation**: Motion/React (Framer Motion)
- **AI**: Transformers.js for offline processing
- **Charts**: Recharts for data visualization
- **Icons**: Lucide React
- **Build**: Vite with TypeScript
